## 1. 게임 정체

- 제목: 「우리는 아직 『 』입니다」 (저장소: `hero-card`, D19)
- 장르: 1:1 대국형 카드 게임 (마작 모티브 — 작혼 참고), 상대는 AI
- 한 줄: 미완의 영웅들로 이야기를 조립해, 라이벌보다 먼저 완성하는 대국
- 핵심 판타지 (원점, D20의 근거):
  1. 수싸움 — 상대의 버림패를 읽고, 내 패를 숨긴다
  2. 기다림 — "내 카드가 나와라" 하고 비는 순간 (텐파이)
  3. 하이라이트 — 완성 선언의 순간이 화면을 잡아먹는 연출
- 제약: 웹 브라우저(HTML/CSS/JS), GitHub Pages 정적 배포, 서버 없음
  → 사람 간 실시간 대전 불가, AI 대국으로 구현
- 제출: NHN 대회 (빌드+소스 / 30~60초 영상 / 게임소개 PDF / AI활용 PDF)

## 2. 세계관 (D10·D11·D12·D32)

- 「미완의 서고」 — 연재 중단으로 결말을 받지 못한 영웅들이 잠든 서고
- 플레이어 = 이야기꾼(사서). 상대(AI) = 라이벌 이야기꾼
- 대국의 의미: 서로 자기 이야기를 먼저 완성하려는 경쟁
- 제목의 『 』 = 아직 제목을 받지 못한 책. 엔딩에서 채워지는 장치
- 톤: 애수 바탕 + 장르 케미의 유쾌함 (D1·D10)
- D32는 잠정 확정 — 유저가 재검토 원하면 이 절만 교체

## 3. 카드 정의 (D28)

- 카드 = 영웅. 속성 2축:
  - 장르 5종: 무협 / SF / 판타지 / 로맨스 / 호러 (D10)
  - 서사 단계 4종: 기 → 승 → 전 → 결 (D37, 옛 기원·시련·각성·승리)
- 5 × 4 = 20종. 각 종 = 영웅 1명 (예: 무협×각성 = "각성한 검객")
- 로스터는 혼합형 (D18): 20명 전형 베이스 + 인연 짝 있는 대표 4~6명만 깊은 사연
- 인연 짝: 특정 두 영웅의 지정 페어 (짝 조건과 가산역 「인연」에 사용)
- 종당 매수(복제 장수)는 미결 — config (마작은 종당 4장, 20종×4=80장이 기준선)

## 4. 대국 룰

### 산 (D22)
- 공유 더미 하나. 엎어진 상태, 순서만 비밀
- 전체 구성표는 양쪽에 공개 → "남은 장수를 센다"가 수싸움의 재료
- 비복원: 뽑으면 줄어들고 되돌아가지 않음
- 산에 카드 심기(설계 요소)는 보류 (D23) — 프로토타입은 고정 구성

### 턴 (D24·D27)
- 내 차례: 산에서 1장 뽑기 → 손패 상한 초과분 1장을 골라 버림
- 손패 8장 고정 (config, 테스트로 재결정 가능 — D27)
- 버림패는 각자 앞에 공개로 쌓임 → 상대를 읽는 재료

### 완성형 (D28·D29)
- 완성 = 손패 8장 전체가 [세트 3장 × 2 + 짝 2장]을 이룸
- 세트 인정 조건 (복수):
  - 장르 세트: 같은 장르 3장
  - 서사 세트(자유): 단계 순서 3장, 장르 무관 — 소점
  - 서사 세트(정통): 같은 장르 안에서 단계 연속 3장 — 고점 (D29)
- 짝 인정 조건: 같은 영웅 2장 또는 인연 짝

### 승부 (D25·D31·D21)
- 한 국 = 먼저 완성을 선언하는 쪽이 승리 (선착 완성)
- 완성 경로 두 가지:
  - 직접 뽑아 완성 (마작의 쯔모에 해당)
  - 운명 뺏기: 상대가 버린 카드로 내 손을 완성 (D31, 마작의 론)
- 매치 = 라운드제: 여러 국을 돌고 점수 누적 (D21). 국 수·종료 조건은 미결
- 국 승리 점수 = 기본점 + 가산역 합산 (5절)

### UI 보조 (D33)
- 성립 중인 세트·가산역·텐파이 여부를 게임이 자동 표시
- 원칙: 찾는 것은 시스템, 판단(무엇을 버릴까·언제 노릴까)은 플레이어
- 연출 원칙 계승: 빠른 기본 템포(D2), 상황 트리거 연출(D3), 전 연출 탭 스킵(D5)
- 연출 투입 지점: 텐파이 진입 / 완성 선언 / 운명 뺏기 / 역만급 — 컷인 하이라이트

## 5. 가산역표 v1 (D30 — 이름·점수 전부 임시)

명명 원칙: 세계관 명칭 + 직관 부제 병기 (D17)

쉬움
- 크로스오버 (1점): 장르 무관 서사 세트 포함
- 단편집 (1점): 장르 세트 2개, 서로 다른 장르
- 인연 (2점): 짝이 인연 짝

중간
- 정통 연재 (2점): 같은 장르 내 연속 서사 세트 포함
- 완결 (2점): 서사 세트가 "승리" 단계로 끝남
- 전속 작가 (3점): 두 세트가 같은 장르로 통일

어려움
- 전집 全集 (5점): 손패 8장 전부 같은 장르
- 대서사시 (6점): 서사 세트 2개가 이어져 기→결 완주
- 오대 장르 (5점): 손패에 5개 장르 전부 등장

역만급
- 불후의 명작 (13점): 전집 + 대서사시 동시 달성

규칙: 가산역은 중복 합산 (예: 전속 작가+완결+인연 = 7점).
역만급은 별도 판정 없이 어려운 역의 교집합으로 정의 → 판정 코드 단순화.

- D38 튜토리얼: 안내 슬라이드 5장 + 첫 판 상황 툴팁 + 완성 정적 예시(독립 모듈)
- D39 난이도 A+B 채택: 혼합 장르 런 불인정 + 최소 2역(config.rules, 시뮬 검증)
- D42 [분기 후보] 특수 능력 시스템: 공유 산 유지 + 점수 아닌 능력형 특수 패.
  능력 3종 확정(예언서=산 위 3장 보기 / 각색=손패 장르 바꾸기 / 복선=버린 패 회수),
  각 1회, 3개 공용으로 시작. "규칙이 마작 같다/테마가 겉돈다" 해법 후보.
  상세·데이터형태·구현순서: docs/분기후보_특수능력.md. 구현 착수 대기.
- D41 AI 전략 레버: 난이도 프리셋(config.difficulty + difficultyPresets)으로

  발견: "뒤지면 참고 큰 손 노리기"는 1:1에서 상대에게 기회를 줘 오히려 약화
  (sim_strategy: 큰 완성 16→18%뿐, 역전 44→36%↓). → 참기는 hard 해법이 아님.
  hard는 자리만, 추후 다른 방식(룰·데이터 또는 3인 역학)으로 재설계.
- D40 수싸움 가시화: ①상대 텐파이 경고만 채택. ②내 위험패 표시는 시뮬 결과
  운명 뺏기를 0으로 죽여(방어형 500국) 긴장 소멸 → 기각. ③내 텐파이 강조는 보류.
  경고는 실제 AI 텐파이 기준(초보 접근성), config.showOpponentTenpai로 토글.
- 기본값(유저 결정 아님, config로 조정 가능): 산 = 종당 3장 × 20종 = 60장 /
  운명 뺏기 후리텐 없음 (v1)

## 7. 미결 사항

밸런스 (config → 시뮬레이션으로 확정)
- 산 구성: 종당 몇 장, 총 몇 장 (기준선 20종×4=80장)
- 가산역 점수표 전체
- 손패 수 최종 확정 (8 vs 11, D27)
- 국 수 / 매치 종료 조건 (선취 N점? 고정 N국?)

룰 디테일
- ~~유국 처리~~ → 확정 D34 (텐파이 소점)
- ~~최소 1역~~ → 확정 D35 (필요)
- ~~매치 구조~~ → 확정 D36 (선취 목표점 + 4국 모드 여지)
- 운명 뺏기 후리텐: v1 없음(기본값), 악용 발견 시 도입 검토
- D11 재해석: "읽히게 하라" 목표를 대국 프레임에 어떻게 얹을지 (예: 국 승리 = 독자를 데려오다)

확장 후보 (v1 이후)
- ③단계: 형태 변형 족보 (속공형 4장 / 대작형 등)
- 산에 심기 재도입 (D23) — 기존 정체성 "확률 설계"의 부활 지점
- 퐁류 콜 (상대 버림패로 세트 공개 완성)
- 특수 패(D14), 낌새 연출(D4)

기술
- AI 상대 설계: 난이도, 성격(라이벌 캐릭터), 사고 시간 연출
- 기존 코드 재사용 범위: store·eventBus·테스트 구조·연출 모듈은 계승 후보,
  gacha/yaku/scoring/round 로직은 대국용 재작성
