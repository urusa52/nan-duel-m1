# 분기 후보 — 완성 대신 "패턴 → 데미지" HP 배틀러 (아이디어, 미구현)

> 상태: 아이디어. 유저 발상(2026-07-22). "일부만 맞추기"의 구체화.
> 목적: 8장 구조의 "다양성 ↔ 길이" 상충과 접근성·독창성 문제를 한 번에 푸는 대안.

## 한 줄

한 판 = 하나의 완성으로 이기는 마작식이 아니라, **여러 맞출 패턴 중 조건을 채우면
부분 점수(데미지)를 내고 상대 HP를 깎는** 카드 배틀러로 전환.

## 왜 (해결하는 문제)

- **길이**: 게임 길이를 **HP로 직접 조절** → "8장이라 너무 빨리 끝남" 문제 해소
  (시뮬 확인: 8장 + 유연한 세트 = 국 길이 중앙값 2~3턴).
- **접근성**: "세트 만들면 공격"이 "8장 완성 + 2역"보다 직관적. 마작 몰라도 이해됨.
- **다양성**: 여러 패턴이 각기 다른 데미지 → 부분 진행이 늘 보상됨(단조로움 해소).
- **독창성**: 작혼 클론에서 벗어남 → "너무 마작 같다 / 테마가 겉돈다"(차별점 분석) 근본 해소.
- **테마 결합**: "이야기 조각으로 라이벌의 미완성 원고를 무너뜨린다"가 규칙에 직접 박힘.

## 대략 어떻게 (초안)

- 양측 **HP**(예: 30).
- 현행처럼 **공유 산에서 뽑고 버리며** 손패 유지.
- 완성된 패턴을 **"선언"하면 데미지** 후 그 카드 소모 → 다시 모음:
  - 짝(주인공) = 약타 / 서사 순서 세트 = 중타 / 삼색·정통 = 강타 / 기승전결 풀아크 = 대타.
- 상대 **HP 0 = 승**. (여러 국 누적 대신 하나의 긴 대결로, 또는 라운드 유지도 가능)
- 특수 능력(예언서·각색·복선)·운명 뺏기·수읽기 **재해석 필요**.

## 참고 감각

- 발라트로 / 족보-배틀러 계열: "족보를 만들어 점수·데미지"의 반복 루프.
  마작보다 대중적으로 읽히고, 부분 완성이 곧 진행이 됨.

## 장점 / 트레이드오프

- 장점: 길이 제어 쉬움 · 접근성↑ · 다양성 보상 · 독창성↑ · 테마 결합↑.
- 트레이드오프:
  - 마작식 **수싸움(상대 읽기)이 약해짐** → 공유 산·상대 공격 공개·운명 뺏기 재해석으로 일부 보존.
  - **밸런스가 새 문제**(데미지 테이블·HP·템포·콤보).
  - **코어 전환** → 해커톤 타이밍엔 리스크(현행 게임이 안전판).

## 재활용 자산 (완전 새 게임 아님)

- 그대로: 카드(장르×단계) 20종, 세트/서사 순서/삼색/역 판정 아이디어, 특수 능력,
  "맞출 수 있는 패" 패널(→ "지금 낼 수 있는 공격" 목록으로 자연 전환), 렌더·연출 틀.
- 바뀜: 승리 조건(완성→HP), 완성 후 흐름(카드 소모·재충전), 점수→데미지 테이블.

## 미정

- 데미지 테이블·HP 값, 카드 소모/재충전 방식, 버리기·운명 뺏기 재해석, 국/단판 구조,
  수싸움 보존 장치(상대 공격 공개 등).

## 결정 (2026-07-22)

- 정체성상 매력적이고 유저 목표(쉽고 독창적·안 빨리 끝남)에 **오히려 더 맞을 수 있음**
  → **v2 강력 후보**.
- 해커톤은 **현행 마작식 유지**로 제출. 이 방향 진행 결정 시 최소 규칙(HP·데미지·패턴별 값)
  설계안부터 → 프로토타입 시뮬로 템포 검증.

## 업데이트 (2026-07-23) — 다음 실험으로 채택

유저 결정: 런 기반 완성(설계_런기반_완성구조_가산역)을 배포한 뒤, **다음 실험**으로
"패턴 하나씩 맞춰 즉각 반응(상대 HP 깎기)"을 시도한다.

- 지금 구조가 좋은 토대가 됨: **세트 = 같은 장르 연속 아크(기승전/승전결)**가 이미
  "맞출 패턴"의 단위라, 여기에 아크별 데미지를 매기면 바로 배틀러가 된다.
  - 기승전(미완 아크) = 약타 / 승전결(결말 아크) = 중타 /
    같은 장르 기→결(일대기) = 강타 / 한 장르 완주(전집·역만) = 대타.
- '완성 후 소모 → 다시 모음' 루프는 현행 완성 판정(yakuEval)을 그대로 재사용 가능.
- HP로 길이를 직접 조절 → 턴 수는 자유롭게(유저: "10턴도 짧다").
- 재해석 필요: 운명 뺏기 / 능력(예언서·각색·복선) / 유국을 HP 모드에서 어떻게 둘지.
- 접근: 현행(완성형 대국)은 그대로 두고, **모드 토글**로 HP 배틀러를 별도 추가하는 방향 검토.
