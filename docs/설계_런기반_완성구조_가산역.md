# 설계 확정 — 런 기반 완성 구조 + 격(등급) 가산역 (2026-07-23)

> 결정: 세트를 "같은 장르 아무 3장"에서 **"같은 장르로 이어지는 서사 3장(기승전/승전결)"**로
> 바꾸고, 완성 채점을 **'축 + 등급'**으로 재설계한다. "게임이 너무 빨리 끝난다"와
> "너무 쉽다"를 인위적 문턱이 아니라 **구조**로 푼다. (구현·검증 완료)

## 배경 / 근거
- 진단(시뮬): 패 수(8→14)는 국 길이 레버가 아님. 실제 레버는 (a) 완성 문턱, (b) 능력(각색), (c) 론.
- 조사(보드게임): 러미(런 vs 그룹), Lost Cities·Ohanami(같은 색 연속 + 커밋 리스크·길이 보상),
  마작 야쿠(패턴 강제)와 **부(符)**(같은 야쿠라도 구성 texture로 점수 차등), Fantasy Realms(동반 카드로 차등).
- 원칙: ① 런을 기본 요건으로 강제 ② 완전한 사가에 점수 몰기 ③ 인위적 '역 개수' 문턱 제거(구조가 난이도).

## 완성 구조
- 손패 8장 = 세트 3장 × 2 + 짝 2장.
- **세트 = 같은 장르의 연속 서사 3장 = 기승전(1-2-3) 또는 승전결(2-3-4).**
  (같은 장르 삼중첩·비연속·혼합 장르 런은 세트 아님. 중복 카드는 짝에만 쓰임.)
- 짝 = 같은 영웅 2장 또는 인연 짝.

## 선언 게이트 (기존 minYaku=3 대체)
- **최소 한 세트가 '승전결'(결말 아크)** 이어야 완성 선언 가능. (기승전만 둘 = 결말 없음 = 불가)
- 테마 "미완의 서고에서 결말을 짓는다"와 일치. 역만은 자동 충족.

## 채점 — 축 + 등급 (중복 합산, 점수는 임시값 · 시뮬로 확정)

**서사 완성도 (세트 두 아크의 조합, 택1):**
- 미완 × 2 (기승전 + 기승전): **선언 불가**
- 양대 완결 (승전결 + 승전결): **2**
- 대서사시·합작 (기→결 완주, **다른 장르**): **3**
- 일대기·연작 (기→결 완주, **같은 장르 = 같은 작품**): **6**
  - ※ '같은 작품'은 지금은 하나의 경우(일대기)로만 기록. 이미지/연출로 세분 구분은 future.

**장르 순도 (가산):** 전집 (8장 전부 한 장르) **+5**
**짝의 격 (가산):** 인연 짝 **+2**
**역만 (단독 대체):** 불후의 명작 = 일대기 + 전집 = **13**

핵심: '대서사시'라는 같은 역 안에서 **다른 장르(합작 3) → 같은 장르(같은 작품 6)**로 격이 갈린다.
각색은 AI엔 잠그고 플레이어에게는 '격 승격' 용도로 유지.

## 삭제된 역
크로스오버·오대 장르(런만 인정 시 불가), 정통 연재(기본 요건 흡수), 단편집·전속 작가(서사 완성도로 통합).

## 구현 위치
- `handEval.classifySet`: 세트 = `sameGenre && isRun`만. `rules.allowGenreTriplet`(기본 off) 앤솔로지 안전판,
  `allowCrossGenreRun`(기본 off) 혼합 런.
- `handEval.waitsFor`: 대기 판정을 `best.declarable`로 필터(승전결 게이트 반영).
- `yakuEval`: 축+등급 채점. 반환 shape 유지(`{score, yaku, decomp, declarable}`).
- `analysis.reachableYaku`: 아크 진척도 기반 '노려볼 역' 새 id로 갱신.
- `config.rules`: allowCrossGenreRun/allowGenreTriplet=false, minYaku 미사용.
